- Create a professional online portfolio.
- Present personal information and academic qualifications.
- Showcase software development projects and technical skills.
- Highlight leadership, volunteering, and campus involvement.
- Provide accessible contact and professional networking links.
- Apply HTML, CSS, and JavaScript concepts in a practical project.

## 6. How to Set Up and Run the Project

### Prerequisites

- A computer with a modern web browser.
- A text editor, such as Visual Studio Code.
- Git, if you want to clone the repository.
- The project files and required image assets.

### Option A — Download from GitHub

1. Open the [GitHub repository](https://github.com/rajvardhanvharambale/rajvardhan-portfolio).
2. Click **Code** and select **Download ZIP**.
3. Extract the downloaded ZIP file.
4. Open the extracted project folder in Visual Studio Code.
5. Confirm that `index.html`, `images/`, and `screenshots/` are present.
6. Open `index.html` in a web browser.

### Option B — Clone the Repository

Open a terminal and run:

```bash
git clone https://github.com/rajvardhanvharambale/rajvardhan-portfolio.git
cd rajvardhan-portfolio
```

Open the folder in Visual Studio Code:

```bash
code .
```

If the `code .` command is unavailable, open Visual Studio Code manually and select the project folder.

### Previewing with Live Server

1. Open the project in Visual Studio Code.
2. Install the **Live Server** extension if it is not already installed.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

The website should open in your browser. You can also visit the deployed website directly:

https://rajvardhanvharambale.github.io/rajvardhan-portfolio/

No `npm install`, Python environment, database configuration, or `requirements.txt` is required to run this static portfolio.

## 8. Technical Details and Architecture

### Application Architecture

The portfolio uses a **static frontend architecture**.

```text
Visitor
   |
   v
Web Browser
   |
   v
index.html
   |
   +-- HTML: Content and page structure
   |
   +-- CSS: Layout and visual presentation
   |
   +-- JavaScript: Interactive behavior
   |
   +-- images/: Profile and project images
```

GitHub Pages hosts the published static files, and the visitor's browser renders the webpage.

### Algorithms and Data Structures

This portfolio is primarily a presentation website rather than a data-processing application.

- **Algorithms:** No complex algorithm is required for the basic portfolio. Small pieces of JavaScript may handle navigation, form validation, and reveal animations.
- **Data structures:** The website does not require a database or complex data structures for its core functionality. Skills, projects, and education are presented as webpage content.
- **Data storage:** The portfolio does not use a backend database to store contact form submissions.
- **Deployment:** GitHub Pages publishes the website from the configured GitHub repository.

This architecture keeps the project lightweight and easy to deploy.
